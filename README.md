📊 Data Professional Survey – Power BI Dashboard 📊

-----------------📌 Project Overview📌----------------------------------------------

This project focuses on analyzing a Data Professional Survey using Microsoft Power BI. 
The dashboard provides insights into the careers, salaries, job satisfaction, and programming language preferences of 630 survey respondents working in the data industry.

------------------🎯 Project Objectives 🎯------------------------------------------

- Analyze salary distribution across different data job roles.
- Understand job satisfaction through salary and work-life balance happiness indices.
- Explore the geographical distribution of survey respondents.
- Identify popular programming languages among data professionals.
- Compare average salaries by gender.
- Examine the demographics of data professionals.

------------------📈 Dashboard Highlights 📈 ------------------------------------------

The interactive dashboard includes:
- Total Survey Takers:** 630 respondents.
- Average Age:** 29.87 years.
- Average Salary by Job Title:** Comparison across different data roles.
- Happiness Index:** Satisfaction levels for salary and work-life balance.
- Country Distribution:** Geographical breakdown of respondents.
- Programming Language Preferences:** Distribution of favorite programming languages.
- Average Salary by Gender:** Gender-based salary comparison.

--------------------🛠️ Tools & Technologies 🛠️----------------------------------------

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## 📂 Project Files
- `POWERBI DASHBOARD.pbip` – Power BI dashboard project file.
- `Power BI - Final Project.xlsx` – Original survey dataset containing 630 responses and 28 columns.
  
## 💡 Key Insights
The dashboard helps explore salary differences across data-related job titles, programming language preferences, geographical representation, and job satisfaction among data professionals.

## 🚀 Purpose
This project demonstrates practical skills in data analysis, data visualization, and business intelligence using Microsoft Power BI, transforming raw survey data into meaningful and interactive insights.
